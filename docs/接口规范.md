# 接口规范
## HTTP 接口
| 方法 | 路径 | 说明 | 请求参数 | 返回结果 |
| --- | --- | --- | --- | --- |
| GET | `/api/instances` | 获取当前所有容器的列表 | 无 | `[{"container_id":"xxx", "name":"xxx", "status":"xxx"}]`|
| POST | `/api/instances` | 创建并启动一个新容器 | `{"name": "测试服1号"}` | `{"status": "success", "container_id": "xxx"}` |
| DELETE | `/api/instances/:id` | 停止并销毁指定容器 | 无 (ID在路径中) | `{"status": "success"}` |
