# MineDock

轻量级游戏服务器容器化管理平台。

## 当前版本进度
- **v0.1.0**: 极简 MVP，基于内存状态跑通后端与本地 Docker 的创建/销毁全链路，提供前端基础交互面板。

## 运行指南
```bash
go run main.go
```
